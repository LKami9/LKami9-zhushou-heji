# LKami9幻化助手

> 本模块属于 [LKami9 助手合集](../README.md)，订阅地址见仓库首页。

从「石之家」幻化截图识别装备与染剂，显示持有情况与获取方式，并可写入游戏内幻化模板。

## 使用

1. 走到投影台前，手动打开投影台并切到「幻化模板」界面
2. 识别截图（「从剪贴板识别」或填路径后「识别这个文件」）
3. 目标模板输入编号（回车确认）→「写入模板」→ 在游戏里点「保存」
4. 点「应用模板」投影

> 「写入模板」与「应用模板」需要投影台的「幻化模板」界面处于打开状态。

## 功能

| 功能 | 说明 |
| --- | --- |
| 截图识别 | 剪贴板图片或文件路径，使用系统自带 OCR，完全离线 |
| 装备与染剂 | 自动判定槽位；模糊匹配会打问号，可粘贴正确名称修正 |
| 持有检测 | 装备栏 / 背包 / 兵装库 / 投影台 / 收藏柜 / 雇员 / 部队箱 / 房屋仓库 |
| 获取方式 | 显示 NPC、坐标、所需材料以及是否可交易 |
| 幻化预设 | 保存识别结果、读取角色查看窗口、导入 Omni 预设、逐部位编辑、复制分享文本、绑定套装 |
| 本地试穿 | 不需要投影台或持有装备，支持装备、染剂、发型和眼镜 |
