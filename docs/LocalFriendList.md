# 本地好友列表

> 本模块属于 [LKami9 助手合集](../README.md)，订阅地址见仓库首页。

在本地记录好友，不受游戏好友栏上限约束；支持名牌上色、同屏检测和一键调起玩家搜索。

## 功能

| 功能 | 说明 |
| --- | --- |
| 本地记录 | 手动输入名字，或对玩家右键「加入本地好友」，可分组、写备注 |
| 名牌颜色 | 附近的好友名牌显示为指定颜色，新增好友立即生效 |
| 同屏检测 | 标注当前同屏的好友，可切换「只看同屏」 |
| 查询在线 | 按 `名字` 打开游戏玩家搜索窗口（国服 `/search name`），查过的行标记「已查」 |
| 点击复制 | 点名字列把「名字@服务器」复制到剪贴板 |
| 改名追踪 | 用账号 ContentId 认人，对方改名后自动更新名字并保留曾用名；悬浮提示可见，搜索兼容旧名 |
| 清理曾用名 | 编辑弹窗里可一键清空某条记录的曾用名（应对反复改名留下的重复项） |

## 使用

1. 打开独立窗口，用「添加好友」输入 `名字@服务器`，或对游戏里的玩家右键选「加入本地好友」。
2. 在设置里勾选「启用好友颜色」，选一个颜色，附近好友的名牌就会变色。
3. 想知道某人是否在线，点行内「查询」，游戏会打开玩家搜索窗口并填入该名字。
4. 手动输入添加的记录没有 ContentId，改名后需在「编辑」里手改名字；右键添加的记录可自动追踪。

## 数据

记录保存在 Omni 模块配置目录下的 `friends.json`，可随时「导出」备份、「导入」恢复。

## 已知限制

- 在线状态只能靠调用游戏搜索窗口间接查看，模块不解析搜索结果，所以列表里的状态是「已查」而不是实时在线。
- 名牌颜色是全好友统一一个颜色（宿主的名牌接口只按玩家粒度着色）。
- 游戏不会为已渲染的名牌重复推送更新，所以颜色同步靠模块主动触发重绘。
- 改名追踪依赖 OmenTools 读取账号 ContentId；若运行环境取不到，会自动降级为「名字+服务器」匹配，
  此时改名仍需手动在编辑弹窗修改。悬浮提示里的曾用名已去重并排除当前名，重复项可用「清理曾用名」按钮清掉。
