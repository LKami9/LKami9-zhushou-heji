# LKami9秘录助手

> 本模块属于 [LKami9 助手合集](../README.md)，订阅地址见仓库首页。

检测传承录 / 秘籍的使用状态，汇总兑换所需材料、持有量与缺口；持有量含 Omni 库存（鞍囊 / 雇员 / 收藏柜 / 部队箱），需 HQ 的材料单独标记，材料名可点击打开制作笔记。

## 功能

| 功能 | 说明 |
| --- | --- |
| 使用状态 | 盘点已使用 / 未使用的传承录与秘籍 |
| 缺口汇总 | 按「还差多少」排序，一眼看出该补什么材料 |
| 持有统计 | 叠加 Omni 库存（鞍囊 / 雇员 / 收藏柜 / 部队箱）与实时容器 |
| HQ 识别 | 商店要求 HQ 的材料单独标记，持有量只按 HQ 计算 |
| 制作笔记 | 点击材料名直接打开对应配方 |
| 一键取回 | 书在雇员 / 鞍囊里时可就地取回 |
| 自动使用 | 按设定间隔逐本使用，战斗 / 读条 / 切图时自动暂停 |

界面入口在 Omni 模块设置页的「打开窗口」，不注册聊天命令。
