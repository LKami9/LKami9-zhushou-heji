# LKami9国服频道私聊守卫

> 本模块属于 [LKami9 助手合集](../README.md)，订阅地址见仓库首页。

监听 Omni 国服频道的私聊，正文命中关键词就自动 `/logout`，也可以只提醒不登出。

## 配置

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 关键词 | 空 | 每行一条，忽略大小写，空行忽略 |
| 匹配方式 | 包含 | 包含 / 完全相等 / 通配符（`*` `?`） |
| 发送者过滤 | 空 | 显示名、服务器名或化名编号，逗号分隔；留空不限 |
| 命中后自动登出 | 开 | 关闭 = 只提醒，可先这样跑一遍验证规则 |
| 登出延迟 | 0 ms | 0 表示立即 |
| 触发冷却 | 10 s | 冷却内的重复命中只写日志 |
| 动作前聊天框提示 | 开 | |
| 同时检测游戏内 /tell | 关 | 备用通道，反射失效时也不至于全盲 |

## 排错

- 日志前缀 `[频道守卫]`，关键日志是 `Information` 级，用 `/xllog` 查看。
- 「已认出类型，等待客户端创建」：先在 Omni 里启用「聊天框优化」并连上国服频道，模块每 5 秒自动重试。
- 「未找到国服频道类型」：Omni 版本低于 1.1.8.0，或频道模块没加载。
- 规则拿不准时点「校验关键词规则」，用第一条关键词做自检。
