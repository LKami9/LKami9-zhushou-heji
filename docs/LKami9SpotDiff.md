# FF14找茬

> 本模块属于 [LKami9 助手合集](../README.md)，订阅地址见仓库首页。

用游戏本体的物品图标拼成左右两幅图，找出右图被改掉的那几处。素材全部来自游戏内物品图标，不依赖任何外部图片，不联网，也不写游戏内存。

## 玩法

打开窗口就直接开始一局，关掉窗口即结算。左右两边是同一批图标，右边偷偷改掉几处：

| 差异类型 | 表现 |
| --- | --- |
| 换图标 | 换成完全不同类别的物品，形状差别明显 |
| 水平镜像 | 图标左右翻过来 |
| 旋转 180° | 图标上下左右都翻 |

点中差异得分，点错扣分并扣 5 秒；「提示」会高亮一处未找到的位置，但要扣 10 秒。

### 计分

| 事件 | 分数 |
| --- | --- |
| 找到一处 | +120 |
| 点错一次 | −20，同时 −5 秒 |
| 过关 | 额外 + 剩余秒数 × 4 |

每过一关，格子数每两关 +1、差异数每两关 +1，上限 10×10 / 8 处。

## 设置

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 每边格子数 | 6 | 4~10 |
| 每关差异数 | 3 | 2~8，开局值 |
| 单关时间 | 90 秒 | 30~300 |
| 显示格子底纹 | 开 | 关掉后只剩图标 |
| 音效反馈 | 开 | 关闭后完全静音 |
| 用聊天提示音通道 | 开 | 勾选走 `1~16` 的聊天提示音，取消走通用 UI 音效（23 开窗 / 24 关窗） |
| 命中 / 点错 / 过关 / 提示音效 | 1 / 24 / 3 / 9 | 每行有独立编号输入框和「试听」 |
| 历史记录 | — | 展开最近 20 局的分数、到达关卡、点错次数 |

最高分存 `LKami9SpotDiff.best.json`，历史存 `LKami9SpotDiff.history.json`，都在 Omni 的模块配置目录下。

## 说明

- 图标池在建池时按**图标 ID + 模型 ID** 双重去重，避免同模型换色的物品在板子上出现两个「长得一模一样」的干扰项。
- 差异不会改变图标尺寸，只用换图、翻转换向这类「图标本身变了」的方式，避免被误认为渲染错误。
- 首次开局会扫一遍物品表建图标池（约 1.7 万个图标），有一次性几百毫秒的停顿，之后不再扫。
