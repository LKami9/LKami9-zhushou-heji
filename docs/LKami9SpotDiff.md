# FF14找茬

> 本模块属于 [LKami9 助手合集](../README.md)，订阅地址见仓库首页。

用游戏本体的图标玩找茬。素材全部来自游戏内图标贴图，不依赖任何外部图片，不联网，也不写游戏内存。

## 玩法

设置页可在两种玩法之间切换，**开局时锁定**，中途改设置不影响当前局。

### 经典找茬

打开窗口就直接开始一局，关掉窗口即结算。左右两边是同一批图标，右边偷偷改掉几处：

| 差异类型 | 表现 |
| --- | --- |
| 换图标 | 换成完全不同类别的图标，形状差别明显 |
| 水平镜像 | 图标左右翻过来 |
| 旋转 180° | 图标上下左右都翻 |

点中差异得分，点错扣分并扣 5 秒；「提示」会高亮一处未找到的位置，但要扣 10 秒。

### 找不同

整屏都是同一个图标，只有一格被换掉 / 翻转 / 镜像。找到就立刻进下一关，形成无限连关。

- **整局共用一个倒计时**，不随关卡重置，时间耗尽即本局结束
- 格子每 3 关 +1
- 每关的差异都经过校验：翻转类会先比对贴图像素，确认这个图标翻过来真的看得出来；换图标会排除「换了 ID 但画的是同一张图」的候选

### 计分

| 事件 | 分数 |
| --- | --- |
| 找到一处 | +120 |
| 点错一次 | −20，同时 −5 秒 |
| 过关 | 额外 + 剩余秒数 × 4（经典找茬） |

经典找茬每过一关，格子数每两关 +1、差异数每两关 +1，上限 10×10 / 8 处。

## 挑战模式

「挑战模式」下拉里可以按来源挑图标，可多选混合（带全选 / 全不选）：

| 模式 | 来源 | 图标数 |
| --- | --- | --- |
| 装备大师 | 装备（按模型去重，排除同模型换色） | 约 9800 |
| 食神 | 食材 + 食品 | 约 400 |
| 海王 | 水产品（鱼类） | 约 1450 |
| 简单模式 | 其余物品（杂货 / 材料 / 家具 / 幻卡等） | 约 5700 |
| PVE高手 | 玩家可用、非 PVP 的战斗技能 | 约 830 |
| PVP高手 | 玩家可用、带 PVP 标记的技能 | 约 160 |
| 生产高手 | 制作技能 | 约 110 |
| 采集高手 | 采矿 / 园艺 / 捕鱼 / 大地使者 职业的技能 | 约 95 |

只勾少量来源时，格子数会自动缩小以适配素材量。

## 设置

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 玩法 | 经典找茬 | 经典找茬 / 找不同 |
| 每边格子数 | 6 | 4~10，开局值 |
| 每关差异数 | 3 | 2~8，仅经典找茬显示 |
| 无限时间 | 关 | 勾选后不再倒计时，也不会因为时间到结束；点错只扣分 |
| 时间（分钟） | 2 | 1~120，可手动填写 |
| 挑战模式 | 物品 | 八类来源任意组合 |
| 显示格子底纹 | 开 | 关掉后只剩图标 |
| 音效反馈 | 开 | 关闭后完全静音 |
| 用聊天提示音通道 | 开 | 勾选走 `1~16` 的聊天提示音，取消走通用 UI 音效（23 开窗 / 24 关窗） |
| 命中 / 点错 / 过关 / 提示音效 | 1 / 24 / 3 / 9 | 每行有独立编号输入框和「试听」 |
| 历史记录 | — | 展开最近 20 局的分数、到达关卡、点错次数 |

最高分存 `LKami9SpotDiff.best.json`，历史存 `LKami9SpotDiff.history.json`，都在 Omni 的模块配置目录下。

## 说明

- 图标池首次构建会扫一遍物品 / 技能表（几百毫秒），之后缓存到 `LKami9SpotDiff.pool.<模式>.json`，游戏更新后自动失效重建。
- 差异不会改变图标尺寸，只用换图、翻转换向这类「图标本身变了」的方式，避免被误认为渲染错误。
- 翻转类差异都经过**像素对称校验**：左右对称的图标（圆盾、铃鼓之类）翻过来看不出区别，就不会被选来做差异。
