# LKami9农村人助手

> 本模块属于 [LKami9 助手合集](../README.md)，订阅地址见仓库首页。

跨服或超域传送落地后，自动把你送到海都（利姆萨·罗敏萨）的大水晶。只做传送，不模拟按键、不寻路、不改内存。

## 设置

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 落地后自动传送 | 开 | 关掉后只提示，不动手 |
| 只在大区变更时触发 | 开 | 取消勾选则同大区跨服也触发 |
| 落地后等待 | 2.0 秒 | 跨服加载慢就往上调 |

界面里能看到当前服务器、当前区域、已记录的服务器，以及「立即前往海都」「重新识别水晶」两个按钮。

## 命令

```
/L9HD GO      立即传送一次
/L9HD rset    清掉服务器记录
```

## 限制

- 海都大水晶必须已解锁，未解锁时界面会明说，不会静默失败。
- 不做城内移动（下层甲板到上层甲板是城内以太网，本模块不碰）。
- 不管副本，副本里传送会被游戏拒绝。
